Beyond the stack: how the system works

Two end-to-end projects demonstrating architecture, quality controls, and operational visibility.

BATCH + INCREMENTAL

Healthcare Claims
Data Platform

Built a healthcare claims platform that turns 900K+ CMS records into analytics-ready datasets, with quality checks and traceability built into the pipeline.

Python → PostgreSQL → dbt → analytics
  • Architecture: Medallion layers separate source ingestion, transformations, and analytics-ready outputs; historical loads and daily increments support different processing needs.
  • Data trust: 12 SQL/dbt checks cover duplicate claims, missing values, invalid payments, and reconciliation mismatches, with automated testing and audit logging.
  • Operations: Airflow orchestrates historical and daily workflows; Grafana exposes freshness, pipeline performance, and claims KPIs.

REAL-TIME STREAMING

Financial Sentiment
Analysis Platform

Built a streaming platform that connects financial-news sentiment with price data for 20 tickers—from event ingestion to continuously refreshed dashboards.

Kafka → Spark → TimescaleDB → Grafana
  • Ingestion: Python producers bring financial news from multiple RSS sources together with stock-price events through Kafka.
  • Processing: Spark Structured Streaming classifies news sentiment, maps headlines to tickers, and persists structured results in TimescaleDB.
  • Reproducibility: Docker Compose integrates Kafka, Spark, TimescaleDB, and Grafana, with automated Spark job submission and dashboards refreshing every 5 seconds.
